INSTRUCCIONES DE ACTUALIZACIÓN - HISTORIA DE USUARIO 3 (Frontend UI)
REPOSITORIO: taller2-frontend
ENTORNO OBJETIVO: Servidor Frontend (Linux/Ubuntu) - Puerto: 3000
====================================================================

1. DETENER EL PROCESO ANTERIOR (HU2):
   - Detener el proceso del servidor Node.js/Express en ejecución:
     pkill -f node || true

2. ACTUALIZAR CÓDIGO FUENTE:
   - Descomprimir el paquete de actualización 'entrega_HU3_frontend.zip':
     unzip -o entrega_HU3_frontend.zip -d /opt/taller2-frontend
     cd /opt/taller2-frontend

3. INICIAR EL SERVICIO EN PUERTO 3000:
   - Configurar variables e iniciar el servicio en segundo plano:
     export BACKEND_URL="http://<IP_PC1_BACKEND>:8080"
     export PORT=3000
     nohup npm start > frontend.log 2>&1 &

4. VERIFICACIÓN DE OPERATIVIDAD (PRUEBA DE HUMO):
   - Abrir http://localhost:3000 en el navegador.
   - Realizar operaciones y verificar que la tarjeta "Historial SoR (Últimas 5)" consulte `GET /api/history` y muestre los registros actualizados en tiempo real.
